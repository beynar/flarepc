# Flarepc

Flarepc is a framework for building typesafe RPC workers and durable objects on Cloudflare. It provides a set of tools to help you build supercharged workers and durable objects with ease.

## Features

- Typesafe worker and durable object RPC calls
- Typesafe websocket
- Standard schema validation all over
- Static file handling
- Rate Limiting
- File Uploads
- Streamed responses
- Typesafe scheduled tasks
- Typesafe queue workers-
